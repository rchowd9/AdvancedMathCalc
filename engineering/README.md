# Engineering Roles

This directory is the central index for the calculator's engineering disciplines:

- Civil
- Mechanical
- Electrical
- Computer
- Chemical
- Aerospace
- Biomedical
- Industrial
- Environmental
- Materials

`index.js` provides the shared `ENGINEERING_ROLES` registry. Existing legacy formula implementations are kept at the project root for backward compatibility; the registry records their source paths and the formula families each role covers.
